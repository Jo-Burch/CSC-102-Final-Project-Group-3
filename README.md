# CSC-102-Final-Project-Group-3
Final Project for CSC 102-1 Group 3 (Jo, Max, Hayden, Sean)
<br>------------------------------------------------------------------------
<br>Developing an interactive “Diffuse the Bomb” challenge that combines movement controls, puzzle‑solving, and high‑stakes decision‑making. 
<br>Players navigate through four distinct quadrants using switch‑based directional input and a number‑pad distance system. 
<br>Each quadrant contains a unique puzzle; completing one safely unlocks a wire on the central bomb. 
<br>After all four quadrants are cleared, the player faces a final 50/50 decision involving two wires — only one is safe. 
<br>The project is fully modular, with each team member responsible for a separate system: movement, quadrant management, puzzle logic, and bomb/wire mechanics. 
<br>Together, these components create a cohesive, tense, and replayable bomb‑diffusal experience.
